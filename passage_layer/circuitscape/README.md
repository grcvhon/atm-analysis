# Generate conductance layer for species distribution modelling

This README goes through the workflow for generating a conductance surface layer based on ocean surface current direction/bearing using the Circuitscape program.<br>

Essentially, we used our generated passage probability layer as the input "surface" for Circuitscape. Recall that this passage probability layer was generated by estimating passage probability among spatially-balanced points placed across our model extent. By calculating the probability of passage among spatially-balanced points, we assume that these values as the null condition, and passage probability taking into account only the prevailing ocean current bearing/direction. That is, based on ocean current direction, what is the probability of moving from this point to any other points.<br>

We then use this output to generate a surface that presents all possible pairwise routes to connect focal nodes. Focal nodes, in this sense, are the general locations/regions (= sites) where specific species have been recorded (e.g. Shark Bay, Exmouth Gulf, Pilbara, Ashmore Reef). For example, all occurrence data from Shark Bay is group in the focal node "Shark Bay" and so on.<br>

Typically, Circuitscape will use "resistance" as input to infer how movement between focal nodes is "resisted" by the environmental variables and find all possible routes around the resistant surface. In our case, we will treat our input as conductance since it represents probability of passage. In population genomics/landscape genomics, the values of resistance or conductance can be used in correlating with genetic fixation indices to infer the presence of Isolation-by-Resistance. For our purpose, we will use the generated conductance surface, the pairwise inference of how focal nodes are likely connected, as a predictor variable in our SDM.<br>
